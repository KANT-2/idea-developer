# 상세 설계 시나리오

이 폴더는 기능별 상세 설계 시나리오와 예외 조건을 설명합니다.

현재 구현의 최우선 기준은 `../requirements/CURRENT_REQUIREMENTS.md`입니다. 아래 시나리오는 세부
정책과 예외를 설명하며, 최우선 기준과 충돌할 경우 그 문서를 따릅니다. 회의 중 메모와 확정 정책을
섞지 않습니다.

- `home-backend-scenario.md`: 홈·PRD 백엔드 시나리오
- `brainstorm-backend-scenario.md`: 브레인스토밍 백엔드 시나리오

정책을 바꿀 때는 관련 문서와 코드·테스트를 같은 PR에서 수정합니다.
