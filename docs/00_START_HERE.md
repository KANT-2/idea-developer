# 00. 여기서 시작하세요

## 우리가 만드는 것

아이디어 디벨로퍼는 PRD 작성, 홈 KPI, 브레인스토밍 캔버스, AI 지원, 코멘트와 기여도 계산을 제공하는 독립 Django 서비스입니다.

## 초보 팀의 작업 원칙

처음부터 완벽하게 외우지 않아도 됩니다. 매 작업마다 아래 순서만 지킵니다.

```text
Issue 또는 작업 확인
→ develop 최신화
→ 내 branch 생성
→ 작은 코드 변경
→ 실행·테스트
→ commit
→ push
→ Pull Request
→ 팀원 review
→ merge
```

## 첫날 할 일

1. Git과 Python을 설치합니다.
2. GitHub 계정을 만들고 저장소 초대를 수락합니다.
3. 저장소를 clone합니다.
4. Git 사용자 이름과 이메일을 설정합니다.
5. 팀장에게 `브랜치 이름`, `파일 경로`, `붙여넣을 코드`, `commit 메시지`를 받습니다.
6. `develop`에서 자기 작업 브랜치를 생성합니다.
7. 미리 만들어진 폴더에 전달받은 파일만 추가합니다.
8. 실행 가능한 범위에서 검사한 뒤 commit, push, `develop` 대상 PR을 만듭니다.
9. 다른 팀원의 PR을 확인하고, 한 단계가 완성되면 `develop`을 `main`에 합칩니다.

## 질문할 때 함께 보내야 할 정보

- 실행한 명령
- 터미널 오류 전체 내용(비밀값은 가림)
- `git status` 결과
- 현재 브랜치: `git branch --show-current`
- 기대한 결과와 실제 결과
